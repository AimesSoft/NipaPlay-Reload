# 数据与安全

本文是隐私说明的操作版，重点说明数据存放位置、网络边界和分享日志时需要清理的内容。完整网络行为见 [隐私与数据](privacy.md)。

## 数据分类

| 数据 | 当前用途 | 当前存储边界 | 建议 |
|---|---|---|---|
| 播放记录、观看历史、界面设置 | 恢复播放和个性化 | 本地 SQLite/SharedPreferences | 可备份，但分享前去除路径和服务器地址 |
| WebDAV/SMB/Emby/Jellyfin 凭据 | 连接媒体源 | 部分配置仍在 SharedPreferences | 使用低权限账号；不要提交配置文件 |
| Bangumi/弹弹play/AI token | 同步或 AI 分析 | 本地配置 | 失效或泄露后立即在服务端撤销 |
| 远程控制授权设备 | 允许局域网设备控制 | 本地配置 | 定期清理不再使用的设备 |
| JS 插件 | 扩展功能 | 插件目录和本地配置 | 只安装可信来源，审查网络请求 |

## 网络暴露面

启用媒体服务器、WebDAV、SMB、AI 防剧透、JS 插件或 Web server 时，应用会产生对应网络请求。远程控制和 Web server 默认应只在可信局域网使用，不应直接暴露公网；若确需远程访问，请在外部反向代理中提供 TLS、身份认证、访问控制和审计。

## 日志脱敏清单

提交 Issue 或发送日志前，删除：

- `Authorization`、Cookie、API key、token、密码；
- 带用户名/密码的 URL；
- 公网 IP、内网 IP、NAS 主机名和完整本地路径；
- 媒体文件名中可能包含的个人信息；
- 远程设备名称、配对码和二维码内容。

## 安全问题报告

请不要在公开 Issue 中发布可复现的凭据、未修复漏洞利用代码或真实用户数据。安全问题请按照仓库根目录的 [SECURITY.md](../SECURITY.md) 联系维护者。
