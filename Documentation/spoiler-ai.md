# AI 防剧透

AI 防剧透会在弹幕加载后，把弹幕文本提交给你配置的 AI 服务，识别并屏蔽疑似剧透内容。它是辅助过滤，不保证识别结果完全准确。

## 配置

在“设置 → AI 防剧透”中选择 OpenAI 兼容接口或 Google Gemini，并填写 API 地址、密钥和模型。OpenAI 兼容接口通常使用 `/v1/chat/completions`；Gemini 可填写到 `/v1beta/models`，应用会按模型补全请求路径。

先保存可用配置，再启用防剧透模式。首次使用前可用少量弹幕测试准确性、响应时间和费用。

## 隐私与成本

- 被分析的弹幕文本会发送至你配置的服务商；请只使用可信端点。
- API key 属于敏感信息，不要写入插件、截图、日志或公开 Issue。
- 分析大量弹幕可能消耗 token、额度和时间；网络失败时应按应用提示回退或重试。
- 开启 AI 调试打印会把原始 AI 返回内容和命中弹幕写入日志，排障完成后应关闭，分享日志前务必脱敏。

详细的数据边界见 [隐私与数据](privacy.md) 与 [数据与安全](data-and-security.md)。
