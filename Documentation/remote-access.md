# 远程访问与局域网控制

NipaPlay 可提供局域网媒体共享、Web server 和远程控制。这些功能方便家庭网络中的多设备使用，但不等同于面向公网的安全服务。

## 推荐配置

1. 只在可信局域网启用服务，优先绑定局域网地址而不是公开网卡。
2. 为远程控制设置强随机口令，并定期移除旧设备授权。
3. 仅共享需要播放的目录；媒体服务器账号使用只读或最低权限。
4. 使用完毕后关闭 Web server/远程控制，并检查监听端口是否已释放。

## 公网访问

不要直接将 NipaPlay 端口映射到互联网。需要远程访问时，应由独立的 VPN、反向代理或零信任网关提供 TLS、身份认证、访问控制、速率限制和日志审计；NipaPlay 本身不承诺这些公网防护能力。

## 故障排查

- 同一局域网不能发现设备：检查防火墙、客户端隔离、AP 隔离和端口。
- 能连接但不能播放：验证共享目录权限、媒体 URL、Range 请求和播放器内核。
- 已授权设备异常：撤销该设备并重新配对；不要通过共享配对码解决问题。

安全与日志脱敏要求见 [数据与安全](data-and-security.md)。
