# 使用指南

## 界面概览

- **顶部导航**：进入主页、视频播放、媒体库、设置、新番更新等功能区域
- **主页**：展示新番推荐、最近观看记录和个性化推荐内容
- **媒体库**：管理本地媒体文件和远程媒体服务器连接

## 播放功能

### 播放控制

- **基础控制**：播放/暂停、进度条拖拽、音量调节
- **播放速度**：支持多档倍速播放（0.5x - 2.0x）
- **全屏模式**：支持全屏播放和窗口化切换

### 弹幕与字幕

- **弹幕显示**：支持开启/关闭弹幕显示
- **字幕管理**：多字幕轨道选择和样式自定义
- **显示设置**：弹幕透明度、字体大小、显示区域等个性化调节
- **手动匹配**：如果发现弹幕匹配有误，播放界面可以手动匹配弹幕
- **发送弹幕**：登录弹弹play账号后，可在播放时发送弹幕互动

### 高级播放体验

- **播放器内核**：可按平台和媒体兼容性选择 Erika、MDK、Media Kit（libmpv）或 Video Player；Media Kit 与 libmpv 不是两套独立选项。Linux 不支持 Erika，tvOS 则固定使用 Erika；选择建议见 [播放器内核](player-kernels.md)。
- **画质和 HDR**：部分平台提供 HDR/EDR、Anime4K、ArtCNN 或原生 GPU 路径。能力受显示器、驱动、内核和当前构建影响，不支持时应回退到 SDR。
- **外部播放器与多窗口**：桌面平台可按设置使用外部播放器或独立播放窗口；关闭窗口前先停止播放，避免同时争用同一媒体源。
- **大屏幕与 tvOS**：大屏模式会调整布局和焦点操作。tvOS 固定使用 Erika；遥控器、HDR 和硬解应以真机验收结果为准。

## 下载与离线媒体

NipaPlay 提供种子和磁力链接下载能力，可在下载器中添加任务、选择保存目录、暂停、继续、删除或从已下载内容播放。使用前请确认你拥有下载和保存内容的合法权利，并保证目标目录有足够空间。详细说明见 [种子下载](torrent-download.md)。

## 远程控制与局域网访问

可以启用局域网媒体共享、Web server 或远程控制，让可信网络内的设备浏览媒体或控制播放。该功能不是公网服务；请使用强口令、仅在可信网络启用，并在完成后关闭。详见 [远程访问](remote-access.md)。

## AI 防剧透与 JS 插件

- **AI 防剧透**：加载弹幕后可将文本发送到你配置的 OpenAI 兼容接口或 Google Gemini，以识别疑似剧透。启用前请阅读 [AI 防剧透](spoiler-ai.md)。
- **JS 插件**：插件可扩展弹幕过滤、播放控制和设置页面；只安装可信来源，并阅读 [插件使用与安全](plugins.md)。

## 账号功能

### 弹弹play账号

- **登录账号**：在设置→账号中登录弹弹play账号
- **观看同步**：自动同步观看进度到弹弹play
- **弹幕互动**：发送弹幕参与社区讨论

### Bangumi同步

- **进度同步**：将本地观看记录同步到Bangumi收藏
- **评分同步**：同步评分到Bangumi个人档案
- **收藏管理**：自动更新Bangumi收藏状态
- **短评功能**：在动画详情页面撰写和查看Bangumi短评
- **访问令牌**：需要在 [bgm.tv](https://next.bgm.tv/demo/access-token) 创建访问令牌

### 播放历史

- **观看记录**：自动记录观看进度和历史
- **续播功能**：支持一键续播上次观看位置
- **历史管理**：查看和管理完整的观看历史记录

## 媒体库管理

### 本地媒体

- **文件扫描**：自动扫描指定目录下的视频文件
- **媒体信息**：显示文件详细信息和元数据
- **分类浏览**：按类型、日期等维度组织媒体内容

### NipaPlay 局域网共享

- **设备互联**：连接同一局域网内其他PC端 NipaPlay 设备
- **直接播放**：无需拷贝，直接播放其他设备上的视频
- **零配置**：无需安装额外服务器软件

### 远程服务器

详细的服务器连接和使用方法请参考 [媒体服务器整合](server-integration.md)。
