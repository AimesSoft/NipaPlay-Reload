# JS 插件使用与安全

JS 插件可扩展弹幕过滤、播放器控制、设置入口和本地存储。插件仅在非 Web 平台运行；完整开发接口见 [JS 插件 API](js-plugin-api.md)。

## 安装前检查

- 只从可追溯、可信的作者或仓库导入插件。
- 阅读 `pluginManifest` 的名称、版本、最低宿主版本、作者、链接和权限声明。
- 不安装来源不明、要求粘贴 API key、要求访问与功能无关地址的插件。

## 权限说明

权限声明决定插件可调用哪些宿主桥接能力，例如 `player.control`、`danmaku.modify`、`ui.dialog`、`storage` 与 `system.override`。它不是操作系统沙箱或独立的网络许可系统；应把插件视为与应用同一信任边界中的扩展。

## 故障处理

插件导致播放、设置或弹幕异常时，先禁用最近导入的插件并重启应用。提交问题时附上插件版本、NipaPlay 版本、平台和脱敏后的错误信息；未经作者同意不要重新分发包含第三方代码的插件包。
