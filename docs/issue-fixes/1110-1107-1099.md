### Windows 工作站

Windows 11，Flutter **3.44.6**，在已登录的 RDP 桌面运行本轮构建，使用真实 Media Kit 内核。

- 用 Win32 原生鼠标滚轮事件操作视频区域：应用音量 **0.50 → 0.55 → 0.50**，内核音量同时变化。
- 挂载真实 SRT 后，画面只有一份字幕；实际 mpv 属性变为 `sub-visibility=no`、`sid=no`。移除后 `sub-visibility=yes`。
- 首页数据中独立测试番剧为 **300000/600000ms、50%**。隐藏到托盘，另一个客户端在真实 Jellyfin 标记已看，再次启动唤起原进程；自动同步后数据库/Provider 为 **位置 0、进度 1**，从继续观看中移除。
- 再次点播该集，实际 Media Kit 位置 **156ms**，正常播放，未从片尾开始。
- 托盘隐藏及第二次启动的窗口恢复通过，原进程保持不变。窗口样式不用于推断任务栏注册状态：window_manager 的 skipTaskbar 实际调用 `ITaskbarList::AddTab/DeleteTab`。

播放器/SRT画面已检查；Windows 首页判断依据为运行中应用的数据库、Provider 和继续观看列表，RDP 静态首页截图未作为视觉证据。

### iOS 模拟器

iPhone 17、**iOS 27.2 arm64 模拟器**，真实 Erika 原生内核及真实 Jellyfin。触摸通过临时入口注入 Flutter `GestureBinding`，命中产品的长按及进度条手势识别器。

- **3 轮长按 2x → 松手**，共 **219 次** UI/原生位置采样；均未倒退。三轮松手前后原生位置分别为 `69354→69579`、`188230→188445`、`248274→248492ms`。
- 松手后实际拖动进度条：预览 **397134ms**，约 2.4 秒后原生位置 **399532ms**，持续递增。
- 真实播放至 EOF 后，再次点播同集，原生位置 **351ms**，正常从头播放。
- 本地 **301571ms / 50.26%**，服务器手动标记已看后刷新：本地变为 **0 / 100%**，从继续观看移除；再次点播原生位置 **270ms**。首页及播放截图已检查。

实测发现 Jellyfin 的 `PlayedItems` 操作**不推进 LastPlayedDate**，因此不能只按该时间拒绝完成态。现对当前账号的明确 `Played=true` 且位置为 0 的状态同步完成标记；非零的二刷进度仍正常续播，活动播放及条件写回保护继续生效。

以上为模拟器实测，尚无物理 iPhone/iPad 验收。
