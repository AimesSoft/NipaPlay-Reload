## 验证

- `flutter analyze --no-pub lib`：无 error。全仓分析会包含已有的 HarmonyOS 插件及第三方测试依赖错误，因此不作为本次主代码通过的依据。
- `cargo check --manifest-path rust/Cargo.toml --lib`：macOS 主机检查通过。
- `swiftc -frontend -parse`：修改的 macOS 图层和 iOS 音量控制 Swift 文件通过语法检查；不等同于 Xcode 编译或设备验证。
- `git diff --check`：通过。
- 按仓库约定未新增测试、未打包应用。

## 上游限制

截至本次核对，[rqbit v9.0.1](https://github.com/ikatson/rqbit/releases/tag/v9.0.1) 是已发布稳定版；[MSE/RC4 PR #633](https://github.com/ikatson/rqbit/pull/633) 仍未合并。升级已完成，RC4 支持本身仍待上游实现进入可用版本。
