## 交付内容

1. **弹幕自动匹配（0 条弹幕 → 两次根因修复）**
   - 根因 A：`playUri` 是 `/api/v1/stream/id/<uuid>`，从 URI 推的"文件名"是 UUID，弹弹按文件名匹配永远失败 → `TvLibraryEpisode` 携带远程库的真实 `name/hash`，播放页用 `matchMode: hashAndFileName` 匹配。
   - 根因 B：match 请求用 GET 查询参数，网关不认（手机版是 **POST + JSON + X-AppId/X-Timestamp/X-Signature 签名头**）→ 已完全复刻手机版请求格式（密钥 `nipaplayv1`/`server-managed`）。
   - 时序：匹配调用移到 `_boot` 最前，不被 Erika load/play 挂起阻塞；[TVDanmaku] 覆盖每跳。
2. **媒体库排序**：剧集**自然排序**（第1话<第2话<第10话，原字符串排序错乱）；排序按钮循环 观看顺序 ↔ 名称（集数模式按用户要求移除）。
3. **剧集标签去重**：`第1话 第10话` 是"序号前缀 + 已含序号的标题"叠加，已去掉前缀。
4. **播放进度**：每 10s + 退出时保存，>3s 自动续播。
