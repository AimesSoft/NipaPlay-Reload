# 数据与恢复

预览版的数据格式可能随版本变化。升级、恢复或批量整理前，退出应用并备份。同一数据目录同一时间只供一个实例使用。

## 数据位置

| 内容 | 位置 | 说明 |
|---|---|---|
| Next 数据根目录 | 应用存储目录下的 `next/` | 包含 `next.db`（媒体库、作品身份与资料、任务、书架和布局等）、`dsh-config.json`、图片和导入的弹幕。[DSH 高级配置](dsh-config.md)页面显示 `dsh-config.json` 的绝对路径，其父目录即数据根目录 |
| 个人 harness | 默认 `~/nipaplay-harness`（Windows 为 `%USERPROFILE%\nipaplay-harness`） | 梨花的指令、记忆、工具和脚本，Git 仓库。实际位置见「设置」→「梨花」→「文件夹」 |
| 本机连接凭据 | macOS、Linux 为 `~/.config/nipaplay/endpoint.json`，Windows 为 `%APPDATA%\NipaPlay\endpoint.json` | `nipa` 命令行连接本机所用，每次启动重新生成，无须备份 |
| 凭据 | 系统凭据保险库（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service） | 模型密钥、账号登录、Mesh 私钥 |
| 媒体文件 | 添加的文件夹、下载目录 | 位于应用目录之外 |

[Linux 无界面版](headless.md)使用独立的数据目录。

## 备份方式

| 方式 | 范围 |
|---|---|
| 复制目录 | 退出应用后复制 Next 数据根目录和个人 harness，包括 SQLite 伴随文件 `next.db-wal`、`next.db-shm` |
| Classic `.npb` 备份 | 可选设置、媒体库、观看历史、剧集匹配、账号几类；不包含 `next.db`、Next 的图片和导入的弹幕、对话和个人 harness。账号部分只含可携带的引用，登录秘密不导出 |
| Classic `.nph` 备份 | 观看历史 |

凭据保存在系统凭据保险库中，复制目录不包含模型密钥、登录状态和 Mesh 私钥。

## 同机恢复

1. 退出应用，另存当前的数据目录。
2. 用备份替换数据根目录和个人 harness。
3. 启动后核对媒体路径、观看进度、对话和凭据。

`.npb` 恢复时先预览并选择类别，部分服务需重启后生效。跨平台、跨版本的目录恢复没有完整的迁移流程，系统沙盒和目录授权可能需要重新授予。

## 迁移到其他设备

- 在新设备上安装、登录、加入组网，凭据和目录授权在新设备上重新配置。
- 设备身份只在一台设备上使用；复制整个 `next/` 目录会使两台设备持有同一身份。
- 个人 harness 可推送到自己的 Git 远端，在新设备上克隆，记忆和工具随之迁移。
- `.npb` 恢复其支持的 Classic 类别。Next 数据的跨设备迁移目前没有完整流程，迁移前保留旧设备上的原件和备份。

在新设备上观看旧设备的媒体库时，[加入组网](../use/devices.md)即可，无须迁移数据。
