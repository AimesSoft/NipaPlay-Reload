# Next 使用指南

## 梨花与媒体库

对话适合提出具体目标，例如查询已有作品、解释播放状态或整理指定资料。先核对梨花给出的结果；写入、删除或覆盖可能需要预览和决定。模型可能出错，也可能因服务、网络或权限失败，不能以回答代替检查实际结果。

Next 启动和下载完成时索引文件，但不会自动执行 Classic 识别；Classic 旧匹配需要显式导入。Classic 与 Next 的运行和 Next 数据库独立，但并非两个完全独立的数据岛：例如观看进度和部分设置仍共享，某些明确的媒体操作会向 Classic 投影。因此切换界面不能视为回滚，先备份再试验。

## 本地视频：从文件到播放

以下以桌面上一个可访问的测试视频为例，避免先对整个大目录做批量修改：

1. 在「设置」→「媒体来源」→「本机文件夹」选择「添加文件夹」，在系统选择器中授权包含测试视频的目录。点击该目录的「扫描」，等待任务完成；「已开始」只表示扫描已启动。返回片库查找文件生成的作品。目录权限、文件格式或扫描错误可能影响结果。
2. 打开作品详情，在作品操作菜单选择「匹配作品…」。在「匹配」中选择资料来源，搜索准确片名，检查候选的标题、年份和类型；选中候选后，给文件指定对应剧集，核对后点击「匹配」。没有可靠候选时不要猜；搜索依赖来源和网络。电影与剧集的文件分配界面不同。
3. 在作品详情的剧集操作菜单选择「弹幕…」。选择「添加弹幕」搜索并核对结果，或在本机使用「导入文件」导入已有弹幕。没有可用弹幕时可跳过；在线匹配并不保证每个文件都有结果。
4. 返回作品详情，点击「播放」或对应剧集，检查画面、声音和弹幕轨道；拖动进度后再次打开，核对续播。播放器不支持格式、文件不可读或来源无弹幕时分别检查对应提示，不要将匹配成功视为播放成功。

上述流程涉及实际身份写入；匹配前确认作品和集数。若作品没有出现在片库，先检查扫描任务与文件授权；不同文件布局、平台和远端文件的界面尚需实机验证。

## 对话历史、上下文和记忆

持久对话历史用于回看；DSH 的上下文压缩将较早内容概括，以便后续请求适应模型窗口，原始持久历史仍可回看。压缩不保证模型记住每个细节。梨花的记忆是另外保存的内容，可在「设置」→「梨花」的「梨花记得的事」查看；各设备的梨花各有自己的记忆。压缩和记忆都不是备份，也不等同于每次请求都发送全部历史。具体预算和生效方式见 [DSH 高级配置](DSH_ADVANCED_CONFIG.md)。

## Mesh 设备组网

以桌面 A 和 iPad B 为例：

1. A 完成模型及运行环境设置，打开 Next 界面并保持应用运行。B 开启 Next。两端登录同一账号，分别在「设置」→「设备」打开「组网」的「加入」，处理加入提示。
2. 在设备列表确认另一台设备在线。B 到「设置」→「梨花」选择 A；若显示「没有运行梨花」，检查 A 的 Next 界面、模型及运行环境。B 发送简单问题，确认回复来自远端会话。
3. 要访问 A 上的媒体，先在 A 添加并扫描文件夹，再在 B 的片库查看对应作品和可播放状态；尝试播放并核对声音、画面和进度。若设备在线但作品未出现，先确认 A 的扫描结果，再检查目录刷新与网络；不要仅凭缓存卡片判断可播放。

两端必须运行、证书有效且网络可直连；局域网、overlay 或自行配置的 SSH 转发可以提供地址，防火墙、NAT 和离线状态可能阻止连接。协调服务负责身份与地址，媒体等数据在设备间直接传输，不提供必然可达的中继。离线时缓存目录可能仍显示，但仅在离线设备上的内容不可播放。

加入意味着信任同账号认证设备访问本机开放的能力和进程能访问的文件，不仅是共享媒体库；没有额外媒体库共享开关。只加入可信设备，检查系统文件权限；可在设备列表移除其他设备。「允许别的设备在这里运行程序」是单独的授权，按需要开启。远端设备拥有各自数据库、对话和记忆；组网不会复制整份数据库。

遇到问题时记录复现步骤、平台、来源、本地或远端及播放内核，并在关于页复制诊断信息。分享日志前检查路径、账号等个人信息；不要发送 API key。
