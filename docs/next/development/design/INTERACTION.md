# Next 界面：交互规范

视觉以 `visual/concept.html` 为准（四个画面：首页、首页·就地对话、详情、对话面板；`?v=home|converse|detail|chat`）。本文件只写交互。

## 文字的原则

界面是产品在说话，不是给开发者看的说明。只用自然的短句；不出现 ID、来源链、“已核对”“由谁认定”、模型名、任务号、调试信息，也不回答用户不会有的疑问。能用画面表达的（进度环、进度条、热度线、头像状态）就不用字。出处、回执、动态都留在数据里，供 Agent 和按需打开的视图使用。

## 全局

- **顶栏**：左侧导航“首页 / 发现 / 片库 / 动态”，当前项下方一个绯红小点；右侧依次是后台任务环（有任务时才出现）、搜索、Nipa 头像。
- **⌘K**：任何页面都能唤起“问 Nipa”，Esc 收起。在首页，⌘K 聚焦首页的输入栏（对话展开时聚焦对话的输入框）；在其他页面，弹出对话侧面板。
- **Nipa 头像不写字，只用状态表达**：
  - 空闲：静止；
  - 思考：外圈缓慢呼吸；
  - 执行：外圈一段细弧在旋转；
  - 等你回答：一个绯红小点轻轻跳动；
  - 有新消息：右上角一个小红点。

  悬停时显示一句话，比如“在想”“在补弹幕”。
- **后台入口**（右上角的环）：列出所有在后台进行的事：NipaPlay 的任务（下载、扫描、取弹幕），以及 Nipa 派出去的帮手。有进度的显示进度；没有进度的显示它现在在做什么和用了多久。每一项都能暂停或停止；帮手点开是它自己的对话。没有在进行的事时，环消失。
- **页面切换**：淡入，同时从 0.98 放大到 1，320ms，ease-out。返回上一页时，保持原来的滚动位置。
- **共享元素过渡**：点击作品卡片进入详情时，卡片的图放大铺满，成为详情页的背景。
- **减少动态效果**（跟随系统设置）：关闭推近、视差、背景跟随焦点和共享元素过渡，只保留淡入淡出。

## 首页

### 首页本身

- **主视觉**：显示 Nipa 摆上来的作品（`ui.shelves.put` 的 hero）。Nipa 没摆时，依次取最近准备好的作品、有更新的作品、继续观看的第一部。背景缓慢推近：20 秒内从 1.00 放大到 1.05。
- **Nipa 的一句话**：在主视觉左上角，内容来自 Agent 给 hero 写的那句话。没有可说的，就不显示。
- **作品信息**：片名 Logo（没有就用宋体标题），一行元信息（评分 · 年份 · 类型 · 集数），两行简介，两个按钮：“播放 第 N 集”和“详情”。
- **输入栏**：常驻在主视觉下方，提示文字是“今天想看什么？”，右侧放 2–3 个建议。建议由当前状态生成，比如继续看什么、什么更新了、“来点轻松的”。点一个建议，等于把这句话说出口。
- **书架**：依次是继续观看（16:9 卡片，带进度条）、Nipa 放上来的书架（书架名由 Nipa 起，比如“适合今晚”）、最近添加。书架横向滚动。悬停卡片时放大到 1.03，并出现圆形播放按钮；点击卡片进入详情；点击播放按钮直接播放。
- **主视觉跟随书架**：悬停在某张书架卡片上停稳 600ms 后，整块主视觉换成这部作品：背景、片名或 Logo、元信息、简介、“播放”按钮，交叉淡入约 400ms。Nipa 的一句话和“正在准备”那一行在预览期间淡出隐去。鼠标离开约 300ms 后，整块回到原来的作品。减少动态效果时不做预览。

### 对话：展开与收起

- **同一个对话**：首页的输入栏、展开的对话页、其他页面的侧栏，是同一个对话。默认是 harness 的主会话；只有用户在会话菜单里点“新的对话”或选了别的会话，才会换成别的会话，并保持到用户再换为止。
- **在首页说话**：输入栏发出的话进入这个对话，对话随之展开成整页：上方是会话标题（点开是会话菜单）和收起按钮，中间是完整的对话记录，底部是输入框。主视觉的图留作背景，压暗。
- **收起**：按收起按钮或 Esc，回到首页原样。对话继续进行：Nipa 的一句话显示它正在做的事（文字上有流光），输入栏的发送键变成停止键；完成后，那句话换成回答的第一句，头像出现红点。点输入栏旁的展开按钮或头像，回到同一个对话。
- **其他页面**：点头像或按 ⌘K 打开侧栏，内容同上。从侧栏回到首页时，侧栏关闭，首页的对话展开。

### 对话记录（展开页与侧栏相同）

- **滚动**：停在用户看的位置。在底部时跟随新内容；往上翻时不动，下方出现“回到最新”按钮。展开或收起任何东西都不移动用户正在看的内容。
- **一个回合按发生的顺序显示**：你说的话（靠右的浅色气泡）；Nipa 边做边说的短句（不加气泡，左对齐，可含简单的 Markdown）；中间做的步骤合成一组，默认折叠，标题概括这一组（“查资料、看片库 · 5 步”，只有思考的组是“Thought for 4s”），进行中前面有跳动的红点；最下方是“Thinking · 0:42”（有命令在运行时是“Working”），文字上有流光。
- **回合结束**：你说的话和最终回答之外的内容，折成一行“Worked for 1m 23s ›”，点开在原位展开。被停止的回合显示“Stopped”，失败的显示“Failed”。用户展开过的步骤组不会被自动折叠。
- **回合进行中说话**：直接进入当前回合（Codex 的 steer），出现在时间线上当时的位置。
- **停止**：回合进行中、输入框为空时，发送键变成停止键。
- **卡片**：挂在回合的回答下方，状态实时更新。
- **不放头像**：过程和回复旁都不放头像。状态词用英文（Thinking、Working、Worked for、Stopped、Failed、Queued），内容用中文。

### 后台在工作时

- **后台任务在跑**：头像保持空闲，任务环显示进度。Nipa 的一句话下方多一行“正在准备”：封面、名字和一条细进度条，点开展开步骤。
- **后续唤醒 Nipa 时**：头像外圈转起来，那句话换成它正在做的事，比如“在补弹幕”。做完后，那句话换成结果。

## 详情

- **进入**：通过共享元素过渡，背景铺满整页，作品信息在左侧。
  - 原名（小字）；
  - 宋体大标题，或片名 Logo；
  - 一行元信息；
  - 两行简介，点“更多”展开；
  - 按钮：“继续 第 N 集”（没看过就是“播放”）、“问 Nipa”、“⋯”。点“问 Nipa”会打开侧面板，并带上这部作品作为上下文。“⋯”里有下载全部、标记看过、移除；移除要二次确认。
- **剧集**：季切换（“第一季 ▾”），下面横排剧集卡片：16:9 截图、大号集号、标题、时长，最下方一条弹幕热度线。看过的集有满的进度条；当前集加白色描边。悬停卡片放大到 1.03，并出现播放按钮；点击直接播放。
- **滚动**：背景以 0.3 倍速视差移动；标题缩小并收进顶栏。

## 对话侧面板

- **打开与关闭**：只在首页以外的页面出现。从右侧滑入，用 420ms 的弹簧动画；后面的页面模糊并变暗。按 Esc 或点击面板外关闭。内容就是上面的对话记录和输入框。
- **等待回复**：超过 3 分钟没有任何事件，显示一句“好像没有回应”，下面两个按钮：“再等等”和“重新发”。不自动中断；用户随时可以停止。
- **需要你回答时**：问题以卡片形式出现，选项是按钮，你也可以直接打字回答。
- **需要你登录时**：出现一张“需要登录 B 站”的卡片，按钮“打开登录窗口”打开 NipaPlay 自己的登录窗口。密码不在对话里输入。
- **切换会话**：标题可以下拉：主对话、新的对话，然后按时间列出其他会话，每个会话的标题取它的第一句话。

## 卡片

卡片由 Agent 调用、NipaPlay 渲染。数据只引用作品、剧集、任务、后续等对象，状态实时从 NipaPlay 读取；Agent 只写给观众看的短句，比如候选理由、步骤名。种类有作品、剧集、候选、准备（步骤 + 进度）、下载、设备。点击卡片进入对应页面。卡片不显示 ID，也不显示过程信息。

## 播放器

- 移动鼠标时显示控制栏。
- 按 ⌘K，画面上方弹出一个小输入框。Nipa 的回复以半透明字幕的样子出现在画面上方，6 秒后淡出。
