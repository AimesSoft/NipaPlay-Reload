# 能力缺口清单

> 2026-10-11，sol 对当前源码只读审计（191 条领域记录；源码中 67 个 Action、128 个设置定义）。
> 要求：NipaPlay 中用户能做的事，Agent 都能做；唯一例外是替用户输入登录密码等秘密——登录由用户自己完成，但 Agent 可以发起。
> 覆盖以“用户能做的事”为准，不以“已经做了多少能力”计数。每补一块，用实验配置中的真实任务验证。

## 影响最大的十个缺口

1. **媒体来源连接、登录发起与选库**：Jellyfin、Emby、SMB、WebDAV、NipaPlay 共享媒体库缺少添加、登录、选库入口。
2. **远程内容发现与浏览**：只能查询已有记录，找不到服务器上尚未播放的新内容。
3. **首次播放新文件 / URL 与目录授权**：`playback.open` 要求已有历史记录。
4. **字幕、音轨的选择与加载**：样式设置齐全，但不能切轨、加载外挂或远程字幕。
5. **版本、清晰度、转码、字幕烧录**。
6. **账号业务与同步**：登录发起、收藏、评分、观看状态、Bangumi 同步、多端同步。
7. **远程访问与局域网配对管理**：Mesh 之外的 Classic 遥控配置。
8. **下载完整流程**：启用下载器、单项下载目录、未入库文件的播放。
9. **外部播放器会话控制**：暂停、定位、关闭、实际进度。
10. **截图 / GIF 的生成与保存**。

## 其他成块缺失

外观、语言、通用设置、插件管理、备份与恢复、快捷键、诊断日志；实验室中 WebDAV 快捷设置子页的 22 项操作。
