# 请求示例

请求写明目标和范围即可，梨花按当前设备的实时能力选择工具。以下按场景列出常用请求。

## 媒体库与资料

| 请求 | 梨花的工作 |
|---|---|
| 「把 ~/Movies/动画 加进媒体库并整理好。」 | 添加并扫描目录，识别作品与剧集，绑定身份，补全资料 |
| 「整理一下最近下载的文件。」 | 识别新入库文件并归入作品 |
| 「这部的资料还缺什么？补齐。」 | 按来源核对缺项，获取并保存 |
| 「这部应该是 2019 年的剧场版。」 | 重新绑定身份，更新资料 |
| 「这两条是同一部作品，合并前列出每集的对应关系。」 | 预览合并，按指示提交 |
| 「把简介改成这段，这张图设为海报。」 | 写入资料覆盖，保留原来源资料 |
| 「导入 Classic 的识别结果。」 | 导入 Classic 中已有的作品匹配 |
| 「在文件管理器里显示这一集。」 | 在文件所在设备上打开文件管理器 |

## 呈现

| 请求 | 梨花的工作 |
|---|---|
| 「在首页摆一排『周末想看』，放这几部，按这个顺序。」 | 创建书架 |
| 「首页大图换成这部。」 | 设置主视觉 |
| 「建一个『没看完的动画』分类，以后符合的也放进去。」 | 创建条件分类 |
| 「隐藏 NAS 的『家庭视频』分类。」 | 隐藏原始分类 |
| 「详情页先放角色，再放演职人员。」 | 调整详情页区块顺序 |
| 「这部的评分只显示 Bangumi。」 | 设置单部作品的展示规则 |

## 下载

| 请求 | 梨花的工作 |
|---|---|
| 「找这部第 3 集的资源，比较字幕组，下载后整理进媒体库。」 | 搜索、比较、下载、入库、识别 |
| 「预览这个种子里的文件，只下第 1 集。」 | 预览文件列表，选择文件下载 |
| 「这个下载完成或卡住时告诉我。」 | 登记后续，在事件发生时回到对话 |
| 「暂停所有下载。」 | 暂停任务 |

## 播放、字幕与弹幕

| 请求 | 梨花的工作 |
|---|---|
| 「继续看这部。」 | 从续播位置打开 |
| 「跳到 12 分钟。」 | 定位并读回实际位置 |
| 「找这一集的中文字幕，设为默认。」 | 查找、导入、标注语言 |
| 「这集加上 B 站的弹幕。」 | 获取弹幕并加入轨道 |
| 「刚才那句台词是什么意思？」 | 读取当前字幕 |
| 「看看当前用的是什么内核，换成 Erika。」 | 读取内核状态，更换内核并重开 |

## 设备与后台

| 请求 | 梨花的工作 |
|---|---|
| 「哪些设备在线？工作站上有这部吗？」 | 查询组网设备和合并媒体库 |
| 「让工作站上的梨花下载这部，好了告诉我。」 | 委托另一台设备上的梨花 |
| 「现在有哪些后台任务？」 | 列出任务及状态 |
| 「每天晚上检查在追的番有没有更新，有就下载并告诉我。」 | 编写巡查脚本，配置定时程序 |

## 账号、设置与记忆

| 请求 | 梨花的工作 |
|---|---|
| 「检查 Bangumi 登录状态，把这部标为看过。」 | 查询账号，更新收藏 |
| 「字幕语言优先用中文。」 | 修改设置，说明生效时机 |
| 「记住我喜欢简体中文字幕。」 | 写入记忆 |
| 「你记得我哪些偏好？」 | 列出记忆 |

## 诊断

| 请求 | 梨花的工作 |
|---|---|
| 「刚才那集为什么打不开？」 | 读取播放状态、来源连接和设备状态 |
| 「哪些目录占空间？哪些缓存可以清理？」 | 查看存储与缓存，给出清理计划 |
| 「检查 NAS 的连接。」 | 测试来源连接 |
| 「帮我整理反馈这个问题需要的诊断信息。」 | 收集诊断、日志和相关回执 |

能力的完整目录见 [Action 参考](../development/ACTION_REFERENCE.md)。
