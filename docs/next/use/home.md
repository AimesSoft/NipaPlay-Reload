# 首页与书架

首页和媒体库的呈现由梨花按用户的描述调整。布局保存在执行调整的设备上。

## 首页

| 区域 | 说明 |
|---|---|
| 主视觉 | 顶部大图，一次显示一部作品。指定后固定显示；未指定时，从最近完成任务的作品、最近可播放的本地作品和继续观看中选取 |
| 系统区域 | 继续观看、今天更新、最近添加、最近播放，内容由数据决定，顺序固定 |
| 书架 | 梨花创建的作品行，带标题和一句说明，按创建顺序排列，行内作品按指定顺序 |

> 在首页摆一排「周末想看」，放这几部，按这个顺序；首页大图用第一部。

> 把「周末想看」里看完的那部拿掉。

书架中的作品须已在媒体库中，有资料记录即可。移除书架不影响作品、身份和文件。

## 媒体库分类

「媒体库」的「整理过」视图按分类浏览。分类有三种：

| 类型 | 内容 | 示例 |
|---|---|---|
| 条件分类 | 按条件持续计算，新入库且符合条件的作品自动加入 | 「没看完的动画」「2020 年以后、评分 8 分以上的电影」 |
| 手选分类 | 指定的作品和顺序 | 「把这几部放在一起，叫『经典』」 |
| 原始分类 | 来源原有的结构，如 Jellyfin 的媒体库、文件夹 | 服务器上的「动画」「电影」 |

条件可组合来源、设备、类型（动画、剧集、电影）、观看状态、类型标签、年份、评分、添加时间。缺少相应字段的作品不满足该条件；服务器上的作品需有已确认的身份才参与条件分类。

分类的顺序、原始分类的隐藏与恢复、「卡片」或「书架」形式、「整理过」与「原始」视图，都可以由梨花或在界面上调整。这些操作只影响本机显示，服务器、共享目录和文件保持不变。

## 图片

- **设置图片**：作品的海报、背景、Logo 和剧集截图可替换为本地图片或 HTTP(S) 图片链接，图片解码验证通过后写入。
- **恢复**：清除替换后，显示来源提供的图片，已设置的图片副本保留。
- **生成图片**：NipaPlay 不含图片生成能力。新图片由用户提供的工具或服务生成后，再交给梨花设置。

## 布局的归属

首页摆放和媒体库布局保存在执行操作的设备上，不在组网设备之间同步。在 iPad 上请桌面的梨花调整布局时，调整作用于桌面；需要在 iPad 上生效时，在请求中指明「在 iPad 上摆」。
