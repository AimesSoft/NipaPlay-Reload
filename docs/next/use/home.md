# 首页与书架

首页和媒体库的摆放大多交给梨花：你描述想要的样子，她调用相应的界面工具。下面说明能调整什么，以及调整后保存在哪里。

## 首页

首页由这些区域组成：

- **主视觉**：顶部大图，一次显示一部作品。你或梨花指定后固定显示；没有指定时，首页会从最近完成任务的作品、最近可播放的本地作品和继续观看里自动挑选。不是轮播。
- **系统区域**：继续观看、今天更新、最近添加、最近播放。有没有内容取决于数据，顺序不能调整。
- **梨花摆的书架**：自建的一排排作品，有标题，可以带一句给观众看的说明。书架按创建顺序显示，书架里的作品按你指定的顺序排列。

可以这样说：

> 在首页摆一排"周末想看"，放这几部，按这个顺序；首页大图用其中第一部。

> 把"周末想看"里看完的那部拿掉。

- 书架里的作品必须已经在媒体库里（有资料记录即可，不要求有本地视频）。
- 移除书架不会删除作品、身份或文件。

## 媒体库分类

在「媒体库」的「整理过」视图里，可以按分类浏览。分类有三种：

| 类型 | 说明 | 例子 |
|---|---|---|
| 条件分类 | 按条件持续计算，新入库的作品符合条件就会自动出现 | 「没看完的动画」「2020 年以后、评分 8 分以上的电影」 |
| 手选分类 | 按你给的作品和顺序 | 「把这几部放一起，叫'经典'」 |
| 原始分类 | 来源原有的结构，例如 Jellyfin 的媒体库、文件夹 | 保留服务器的"动画""电影"分类 |

条件可以按来源、设备、类型（动画/剧集/电影）、观看状态、类型标签、年份、评分、添加时间组合。资料里缺少年份、评分的作品，不满足对应条件；服务器上的作品要先有确认过的身份，才能进入条件分类。

另外还可以：

- 调整分类顺序；
- 隐藏和恢复原始分类；
- 切换卡片或书架形式；
- 在「整理过」和「原始」之间切换。

这些操作只影响本机显示，不改动服务器、共享目录或文件。

## 图片和资料

- **换图**：「用我给你的这张图做《某作品》的背景」。可以设置作品的海报、背景、Logo，以及剧集截图。图片可以是本地文件或 HTTP(S) 链接；会先解码确认可用，再写入。
- **恢复**：「把它的海报恢复成原来的」。清除覆盖后，重新显示来源提供的图片，你设置过的图片副本仍然保留。
- **生成图片**：NipaPlay 本身不生成图片。设置图片只是"换成已有的图"；要生成新图，需要你另外提供生图工具或服务，生成后再交给她设置。

详情页上各项资料用哪个来源、区块顺序怎样排，见[媒体库与来源](library.md#修改资料)。

## 布局保存在哪里

首页摆放和媒体库布局保存在**执行操作的那台设备**上。

- 在 iPad 上让桌面的梨花调整布局时，改的是她所在设备（桌面）的布局。
- 布局不会自动同步到组网里的其他设备。
- 想在某台设备上看到某个布局，就让那台设备的梨花去摆，或者明确说"在 iPad 上摆"。
