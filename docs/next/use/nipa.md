# 和梨花对话

## 一次对话里发生了什么

你发出一句话后：

1. 运行器（DSH）把你的话、对话上下文，以及 NipaPlay 当前提供的工具清单交给模型。
2. 模型决定先做什么。需要信息或要执行操作时，它会调用工具。工具由 NipaPlay 提供，例如查询片库、搜索资料、添加下载、播放、修改设置。
3. NipaPlay 执行工具，把结果交回模型；模型根据结果继续调用工具，或者给出回答。

所以梨花知道的东西都来自**当次查询的结果**，而不是凭记忆猜测。工具清单和参数可能随版本和设备变化，她每次工作前会重新查询。

## 看她做了什么

- **工作步骤**：回答上方会依次列出她调用的工具，用动作描述，例如「翻媒体库」「查资料」「认文件」「添加下载」「看下载」「改设置」「运行命令」。点开可以看到工具的输出。没有任何步骤的回答，说明她没有调用工具，只是在凭模型知识回答。
- **结果卡片**：作品、剧集、下载任务、可选项会以卡片形式出现在回复下方，卡片状态会随数据更新。
- **后台的事**：下载、扫描、批量整理这类耗时操作会变成后台任务。对话里显示「这次对话在后台做的事」，顶栏「动态」→「进行中」可以看到全部任务。

**"已受理"不等于"已完成"。** 下载开始、扫描开始，只代表任务已经提交。结果要看任务状态，或者让她等任务结束后告诉你。

**结果未知不等于失败。** 网络中断或超时后，工具结果里可能出现 `outcome_unknown`（结果未知）；用 iPad 和远端设备上的梨花对话时，也可能显示「某某 没有回应，这句话可能已经送到了」。这时操作可能已经生效。正确的做法是查询任务或回执确认，而不是直接重做一遍。详见[常见问题](../help/faq.md#任务超时了到底写入没有)。

## 怎样提要求

把目标、范围和要保留的东西说清楚，不需要知道工具名：

- 好的说法：「把《某作品》第 1 到 12 集和下载目录里的文件对应起来，先列出对应关系给我看，不要直接改。」
- 不够清楚的说法：「整理一下媒体库。」范围太大，她只能猜你想要什么。

几个习惯：

- **批量修改前先要预览**：「先预览」「先列出来等我确认」。合并作品、SQL 修改等操作支持预览，提交后保留回执，满足条件时还能撤回。
- **身份类操作要核对**：认错的作品会带错资料和弹幕。让她说出依据（标题、年份、集数、文件时长）。
- **随时补充或改主意**：她工作时输入框显示「补充，或者改主意」，可以直接发新的要求；也可以点「停止」中断。
- **在页面上直接问**：在作品详情页或播放时打开对话，她会知道你说的是哪一部、哪一集。

## 确认、提醒与提问

- **确认**：删除下载的文件、部分敏感设置和受保护的网络设置，会弹出确认或要求你明确授权。但这不覆盖所有操作：她拥有完整的用户级权限，通过命令行或脚本改动文件时不一定会再询问。
- **提醒**：你可以让她"下载完告诉我""全部做完再告诉我"。提醒出现在右下角，多条可以切换，也可以收起成一条小提示；在「全部提醒」里能找到历史提醒。
- **提问**：她需要你决定时，会在右下角提问，同时继续做不依赖答案的工作。你可以点选项，也可以直接回复；收起的问题仍可在提醒列表里找到。
- **运行失败**：显示「梨花运行失败」和收到的错误原文，可以用「复制完整错误」复制下来反馈。

## 帮手

任务可以拆开并行时，梨花会"派帮手"：另开一个对话处理其中一部分，例如同时为几部作品补资料。对话里可以「打开帮手的对话」查看进度，也可以让她「收回帮手」。

## 主对话与新的对话

点对话顶部的标题，会列出所有对话：

- **主对话**：一直保留的那条对话。定时程序和脚本叫醒梨花时（`agent.wake`），默认送到这里。
- **新的对话**：从空白开始，不带之前对话的上下文，但她的记忆和个人 harness 仍然在。换一个不相关的话题，或者主对话已经很长时，开一条新的更合适。
- 其他对话按最近使用排列，标题取自你说的第一句话。

## 对话历史、上下文压缩和记忆

这三样东西经常被混淆：

| | 是什么 | 在哪里 |
|---|---|---|
| 对话历史 | 你和她说过的全部内容，完整保存 | 对话里向上翻，会继续加载更早的内容 |
| 上下文压缩 | 对话太长时，DSH 把较早的部分概括成摘要，让后续请求放得进模型的上下文窗口 | 自动进行；原始历史仍然完整，可以回看 |
| 记忆 | 她主动记下的偏好和经验，例如"你喜欢中文字幕" | 「设置」→「梨花」→「梨花记得的事」，可以查看和忘掉 |

- 压缩后的模型不保证记得每个细节。重要的要求可以让她"记下来"，或者在新请求里再说一次。
- 记忆按设备保存，每台设备上的梨花各有各的记忆。
- 记忆和历史都不是备份。不要让她记密码或 API key。

压缩的触发时机和预算可以在 [DSH 高级配置](../advanced/dsh-config.md) 里调整。

## 梨花的文件夹

每个人有一个属于自己的 Git 仓库（个人 harness），保存梨花的工具、脚本、记忆和事件脚本。位置可以在「设置」→「梨花」→「文件夹」里查看和修改。

- 她可以在工作中补充脚本、记录经验；你也可以直接打开文件查看、修改，用 Git 管理历史。
- 应用升级时，官方提供的种子文件会合并进来，保留你的修改；遇到冲突会报告，不会覆盖。
- 详见[自动化与个人工具](../advanced/automation.md)。

## 她改过的设置

梨花修改过的应用设置列在「设置」→「梨花」→「梨花改过的设置」，可以检查和撤销。
