# 和梨花对话

## 一轮对话

1. 运行器把消息、对话上下文和 NipaPlay 当前提供的工具清单交给模型。
2. 模型决定调用哪些工具。工具由 NipaPlay 提供，涵盖媒体库查询、资料检索、下载、播放、设置等。
3. NipaPlay 执行工具并返回结果，模型据此继续调用工具或给出回答。

梨花的判断依据是当次查询到的实时状态。工具清单和参数随版本、设备变化，梨花每次按实时目录调用。

## 工作过程

| 元素 | 说明 |
|---|---|
| 工作步骤 | 回答上方按顺序列出工具调用，以动作描述，如「翻媒体库」「查资料」「认文件」「添加下载」「看下载」「改设置」「运行命令」，展开可见工具输出 |
| 结果卡片 | 作品、剧集、下载任务、选项以卡片显示在回复下方，状态随数据更新 |
| 后台任务 | 下载、扫描、批量整理等在后台运行。对话中「这次对话在后台做的事」列出本对话发起的任务；「动态」→「进行中」列出全部任务 |

后台任务以任务状态和回执记录实际结果。网络中断或超时时，工具结果可能为 `outcome_unknown`，此时操作可能已经生效，以任务和回执为准，见[常见问题](../help/faq.md#任务超时了到底写入没有)。

## 请求

请求写明目标、范围和需要保留的内容，无须指定工具。

> 把下载目录里第 1 到 12 集对应到这部作品，资料补齐。

> 合并这两条重复的作品，提交前列出每集的对应关系。

- 梨花工作时，输入框提示「补充，或者改主意」，可随时追加要求；「停止」中断当前回合。
- 在作品详情页或播放器中打开对话，梨花获得当前作品、剧集和播放位置。

## 授权与确认

梨花按对话中的授权执行操作。NipaPlay 在以下情形要求本机确认或明确授权：

| 操作 | 方式 |
|---|---|
| 删除下载的文件 | NipaPlay 在本机弹出确认 |
| 删除其他设备上的文件、覆盖文件 | 梨花在对话中取得同意后执行 |
| 受保护的网络设置 | 在对话中明确授权后由梨花配置 |
| 账号登录 | 在 NipaPlay 的登录窗口中完成 |

梨花通过命令行、脚本或 SSH 执行的操作不经过 NipaPlay 的确认。

## 提问与提醒

- **提问**：需要用户决定的事项出现在右下角，可点选项或直接回复。梨花继续不依赖答案的工作，回答回到原对话。收起的问题保持待答，在提醒列表中可以找到。
- **提醒**：阶段结果或完成时，梨花发出提醒，内容和时机由梨花按请求和偏好决定。多条提醒可切换，可收起为一条提示，历史在「全部提醒」中。「设置」→「梨花」→「梨花提醒浮窗」控制浮窗显示。
- **运行失败**：显示「梨花运行失败」和收到的原始错误，「复制完整错误」复制全文。

## 帮手

可并行的工作，梨花分给帮手处理，每个帮手是一个独立对话，例如同时为几部作品补资料。对话中「打开帮手的对话」查看进度，也可以请梨花收回帮手。

## 主对话与新的对话

点对话顶部的标题，列出全部对话：

| 对话 | 说明 |
|---|---|
| 主对话 | 常驻对话。脚本和定时程序唤醒梨花（`agent.wake`）时默认进入这里 |
| 新的对话 | 从空白上下文开始，记忆和个人 harness 照常可用 |
| 其他对话 | 按最近使用排列，标题取自第一句话 |

## 对话历史、上下文压缩和记忆

| | 内容 | 位置 |
|---|---|---|
| 对话历史 | 完整的对话记录 | 对话中向上滚动加载 |
| 上下文压缩 | 对话超出预算时，运行器把较早部分概括为摘要，后续请求使用摘要；原始历史保留 | 自动进行，预算见 [DSH 高级配置](../advanced/dsh-config.md) |
| 记忆 | 梨花记录的偏好和经验，跨对话生效 | 「设置」→「梨花」→「梨花记得的事」，可查看和删除 |

- 压缩后，较早对话的细节以摘要形式保留。需要长期遵守的要求，请梨花写入记忆。
- 记忆按设备保存，各设备上的梨花分别维护。
- 密码和 API key 不写入记忆。

## 梨花的文件夹

个人 harness 是一个 Git 仓库，保存梨花的指令、记忆、工具和脚本，位置见「设置」→「梨花」→「文件夹」。梨花在工作中补充工具和经验，用户可以直接编辑，用 Git 管理历史。结构见[自动化与个人工具](../advanced/automation.md)。

## 梨花改过的设置

「设置」→「梨花」→「梨花改过的设置」列出梨花修改过的应用设置及修改原因，点击进入对应设置项。
