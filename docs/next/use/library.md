# 媒体库与来源

## 来源

Next 的媒体库把多个来源合在一起显示。来源在「设置」→「媒体来源」里管理：

| 来源 | 添加方式 | 说明 |
|---|---|---|
| 本机文件夹 | 「本机文件夹」→「添加文件夹」，再「扫描」 | 扫描登记文件，不改动文件本身 |
| SMB 共享 | 「添加」→ SMB，填主机、端口、用户名和密码；「附近」可以发现局域网里的共享 | 需要网络可达 |
| WebDAV | 「添加」→ WebDAV，填地址、用户名和密码 | 同上 |
| Jellyfin / Emby | 「添加」→ Jellyfin 或 Emby，填地址后「登录」；Jellyfin 可以用「在服务器上批准」（Quick Connect），不用输入密码 | 作品、季、剧集和资料会保存下来，可以和本地作品统一管理 |
| 其他设备 | 加入[组网](devices.md)后自动出现 | 视频留在原设备，播放时直连传输 |

- 每个来源都可以「检查」连接，结果显示「连接正常」或「连不上」。
- 密码保存在系统凭据保险库里，失效时会提示「需要重新输入密码」。
- 「移除」来源只会删掉 NipaPlay 里的记录，不删除原文件。

**离线来源的作品仍会显示。** 来源暂时连不上时，片库里可能还显示上次读到的目录，但这些文件此时无法播放。

## 浏览媒体库

「媒体库」页面有两种浏览方式：

- **整理过**：按作品显示，可以按分类浏览，也可以切换「卡片」或「书架」形式。分类可以自己建，见[首页与书架](home.md)。
- **原始**：按来源原有的结构浏览，例如服务器的媒体库或文件夹的目录。可以「隐藏」不想看的原始分类，或「调整」顺序。这些操作只影响本机显示，不改动服务器或共享目录。

点「选择」可以多选作品，批量执行「匹配」「刷新资料」「移除」「解除匹配」，或者「让梨花整理」。

## 作品身份：匹配

Next 把文件和作品分开记录：扫描登记**文件**，匹配建立**身份**（作品、季、集与文件的对应关系），并保存外部平台的编号（TMDB、Bangumi、弹弹play）。身份决定了资料、图片、弹幕和观看进度归到哪里。

- **界面匹配**：作品详情的操作菜单 →「匹配作品…」，选资料来源、搜索、核对候选，把文件对应到剧集，点「匹配」。做法见[第一次使用](../start/first-day.md#2-匹配作品)。
- **交给梨花**：「检查这个文件可能是哪一集，先列出候选和依据，等我确认。」她会用文件名、时长、来源资料做判断，确认后再写入。
- **解除匹配**：作品菜单里「解除匹配」会撤掉身份，文件回到未匹配状态，不删除文件。
- **Classic 的匹配**：不会自动导入，需要明确让梨花导入。

几种需要留意的情况：

- **重复作品**：同一部作品出现两条时，可以让她"先预览合并和每集对应关系"。合并提交后保留回执，满足条件时可以撤回；之后如果关系又有变化，可能就撤回不了了。
- **一个文件多集**：合集文件可以按时间区间对应到多集，交给梨花处理更方便。
- **移除作品**：「移除作品」只从媒体库移除记录，原文件留在原处。

## 作品详情页

匹配后，详情页显示：

- **首屏**：背景、标题、评分、简介、导演或主创、观看进度，以及「播放」或「继续播放」。
- **剧集**：按季列出，每集的操作菜单里有「弹幕…」「字幕…」「文件…」，可以标记看过或没看过。
- **演职人员、角色与声优**：点人物进入人物页，可以看到照片、简介、在媒体库中的作品和参与作品。
- **图片**：剧照和海报，可以全屏查看。
- **完整资料**：原名、首播与完结、状态、季数集数、制作公司、电视网、国家与语言、标签、外部链接等。
- **文件信息**：画质（分辨率、HDR、编码）、音轨和字幕轨。
- **同系列作品**：同一系列的 TV 版、剧场版等，来自 Bangumi 关联条目、TMDB 合集和弹弹play。

资料取决于来源，缺项往往是来源本身没有这项数据。

### 修改资料

- 作品菜单 →「编辑资料…」可以修改标题、原名、简介，以及海报、背景等图片；也可以「恢复」为来源原本的资料。
- 也可以让梨花改：「把简介改成这段，这张图设为海报，保留原始来源。」图片需要是可读取的本地文件或 HTTP(S) 链接。
- **资料来源与展示规则**：同一项资料常有多个来源（TMDB、Bangumi、弹弹play 的标题、简介、评分）。梨花知道页面上每个位置显示的是哪个来源，可以按你的要求调整，对全部作品或单部作品生效。例如：「这部的简介改用 Bangumi 的，评分只显示 Bangumi。」「详情页先放角色，再放演职人员，图片放最后。」
