# 媒体库与来源

## 来源

媒体库合并显示所有来源的作品。来源在「设置」→「媒体来源」中添加和管理：

| 来源 | 添加方式 | 内容进入媒体库的方式 |
|---|---|---|
| 本机文件夹 | 「本机文件夹」→「添加文件夹」 | 添加后立即扫描，扫描结果交给梨花整理 |
| SMB 共享 | 「添加」→ SMB，填写主机、端口、用户名和密码；「附近」列出局域网中发现的共享 | 读取目录后进入媒体库 |
| WebDAV | 「添加」→ WebDAV，填写地址、用户名和密码 | 同上 |
| Jellyfin、Emby | 「添加」→ Jellyfin 或 Emby，填写地址后「登录」；Jellyfin 支持「在服务器上批准」（Quick Connect） | 服务器上的作品、季、剧集和资料保存到本机 |
| 其他设备 | 加入[组网](devices.md)后出现 | 目录合并显示，视频留在所在设备 |

- 「检查」测试来源连接，结果为「连接正常」或「连不上」。
- 密码保存在系统凭据保险库中；失效时，来源显示「需要重新输入密码」。
- 「移除」删除 NipaPlay 中的来源记录，原文件保持不变。
- 来源离线时，媒体库保留上次读取的目录，其中的文件在来源恢复前无法播放。

除 GUI 添加的本机文件夹外，来源内容的识别和资料补全由用户在对话中提出：

> 整理 NAS 上「动画」目录里的作品，资料补齐。

## 作品身份

NipaPlay 分开记录文件与作品。扫描登记文件；身份确定文件属于哪部作品、哪一季、哪一集，并关联外部平台的条目（TMDB、Bangumi、弹弹play）。资料、图片、弹幕和观看进度按身份归属。

梨花负责身份与资料：

- 从文件名、目录结构、时长和来源资料判断作品与集数；
- 绑定 TMDB、Bangumi、弹弹play 中能核实的条目；
- 获取并保存中文标题、简介、海报、背景、Logo、剧集标题和截图，记录每项资料的来源；
- 处理一个文件包含多集、同一作品出现多条等情况，合并重复作品时可先预览每集的对应关系；
- 来源未收录的作品保留本地身份，可播放的内容照常可用。

存在多个可能的作品且无法核实时，梨花以提问的形式请用户选择。

NipaPlay 自身的识别限于弹弹play 的文件哈希匹配，用于在没有身份时加载弹幕。Classic 中已有的识别结果，可以请梨花导入。

### 修正与手动修改

识别有误时，在对话中说明正确的作品，梨花重新绑定并更新资料。作品详情的操作菜单另提供：

| 入口 | 作用 |
|---|---|
| 「匹配作品…」 | 直接修改作品身份，或「解除匹配」 |
| 「编辑资料…」 | 修改标题、原名、简介和图片；「恢复」为来源资料 |
| 「移除作品」 | 从媒体库移除记录，原文件保持不变 |

合并作品保留回执；相关数据此后未再变化时，可以撤回。

## 浏览

「媒体库」页面有两种视图：

- **整理过**：按作品显示，按分类浏览，可切换「卡片」或「书架」。分类见[首页与书架](home.md#媒体库分类)。
- **原始**：按来源原有的结构显示，如服务器的媒体库和文件夹目录。可以「隐藏」或「调整」原始分类，这些操作只影响本机显示。

作品卡片的菜单中「选择」进入多选，可对选中作品「刷新资料」。分类菜单中的「让梨花整理」把分类的整理交给梨花。

## 作品详情

| 区块 | 内容 |
|---|---|
| 首屏 | 背景、Logo 或标题、评分、简介、导演或主创、观看进度、「播放」或「继续播放」 |
| 剧集 | 按季列出；每集的菜单包含「弹幕…」「字幕…」「文件…」，以及标记看过或未看 |
| 演职人员 | 演员、角色与声优、主创；点人物进入人物页，显示照片、简介、媒体库中的作品和参与作品 |
| 图片 | 剧照和海报，可全屏查看 |
| 完整资料 | 原名、首播与完结、状态、季数与集数、制作公司、电视网、国家与语言、标签、外部链接 |
| 文件信息 | 分辨率、HDR、编码、音轨、字幕轨 |
| 同系列作品 | 来自 Bangumi 关联条目、TMDB 合集和弹弹play |

各区块的内容取决于来源收录的资料。

### 展示规则

同一项资料常有多个来源，例如 TMDB、Bangumi、弹弹play 各自的标题、简介和评分。梨花可以按要求指定每个位置使用的来源、评分的显示方式、区块顺序和每行数量，对全部作品或单部作品生效：

> 这部的简介用 Bangumi 的，评分只显示 Bangumi。

> 详情页先放角色，再放演职人员，图片放最后。
