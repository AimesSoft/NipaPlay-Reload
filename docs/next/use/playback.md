# 播放

## 开始播放

在作品详情点「播放」「继续播放」或某一集。播放器会立即打开，显示片名和加载状态；弹幕在后台准备，不会挡住开播。左上角返回可以取消这次打开。打不开时会显示「这一集现在打不开」，片刻后退出；原因记在播放状态里，可以问梨花「刚才那集为什么打不开」，排查方法见[常见问题](../help/faq.md#这一集现在打不开)。

一集可能有多个来源（本机、其他设备、Jellyfin/Emby）。剧集菜单里的「文件…」列出每个文件及其所在设备。远端设备离线时，只存在于那台设备上的文件无法播放。

## 播放器菜单

- **字幕**：选择字幕轨、「添加字幕文件…」、时间偏移；「样式」可以调颜色、字体、粗体斜体、不透明度、描边、阴影、位置、对齐和边距，以及 ASS 字幕的样式覆盖（只列出当前内核能改的项）；「字幕列表」列出全部台词，点击跳转。
- **弹幕**：开关、速度、透明度、合并相同弹幕、时间偏移；「样式」「屏蔽词」；「弹幕轨道」可以开关、移除、「添加弹幕文件…」；「弹幕列表」点击跳转；「发送弹幕」（需要登录弹弹play）；「保存为 JSON」「保存为 XML」。
- **音轨**、**剧集**：切换音轨，切换到同一作品的其他集。
- **「⋯」更多**：
  - 倍速（可以手动输入）、画面比例；
  - 截图、截取 GIF、画中画、分离窗口、章节；
  - 「播放设置」：快进快退步长、长按倍速、进度条预览、进度条上的弹幕密度；
  - Jellyfin/Emby 来源的清晰度：原画、转码；
  - 「播放信息」：内核、来源、容器、分辨率、编码与码率、动态范围、帧率、解码方式、音频；底部「复制诊断」复制完整的播放诊断信息，反馈问题时附上。

快捷键：空格暂停、左右方向键快退快进（右方向键长按按设定倍速播放、松开恢复）、`.` 和 `,` 逐帧前进和后退。Alpha 2 的 Next 播放器使用固定快捷键，还不读取「设置」→「快捷键」。

## 播放器内核

「设置」→「播放」→「播放器内核」决定由哪个引擎解码和渲染。可选项因平台而异：

| 内核 | 特点 |
|---|---|
| Erika | NipaPlay 自研内核（Rust）。按平台使用 Metal、D3D11 或 Vulkan，原生视图输出 HDR/EDR；字幕（含 ASS）和弹幕由内核直接绘制在画面里；提供实时神经超分辨率 |
| MDK | 稳定的硬件解码，格式支持广 |
| Media Kit（libmpv） | mpv 的格式兼容性；可以加载 Anime4K 着色器（「Anime4K 画质预设」） |
| Video Player | 系统播放器，兼容性取决于系统 |

切换内核后，从下一次打开媒体开始生效。字幕样式和弹幕设置是共用的，但各内核能应用的项目不同，菜单里只显示当前内核支持的项。

Erika 的「Erika 超分辨率」在「设置」→「播放」里，适合低分辨率的动画片源，对 GPU 有一定压力。

## 字幕与弹幕从哪里来

- **字幕**：视频内嵌的字幕轨；同目录的外挂字幕；播放器里「添加字幕文件…」导入的文件，导入后保存为应用数据。也可以让梨花找字幕、导入、标注语言并设为默认。
- **弹幕**：按作品身份从弹弹play 等来源获取，作品要先匹配好。获取后持久保存，再次播放直接使用。可以在剧集菜单「弹幕…」里添加或导入，也可以让梨花准备。
- 播放中读取当前字幕台词等能力，供梨花在"这句台词是什么意思"之类的请求中使用。

## 续播与观看记录

- 播放会记录进度，下次从该位置打开（Erika 会直接从续播位置开播，第一帧就是续播处）。
- 顶栏「动态」→「观看记录」列出最近看过的内容；作品详情里可以把剧集标为看过或没看过。
- 观看进度和 Classic 共用；绑定了 Bangumi 时，可以在「设置」→「账号」开启观看记录同步。

## 边看边和梨花说话

播放时打开对话，梨花知道你在看哪一集、播到哪里。可以说「跳到 12 分钟」「换成中文字幕」「这一集的弹幕太密了，屏蔽这几个词」。
