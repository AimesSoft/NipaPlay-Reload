# 播放

## 打开

作品详情中的「播放」「继续播放」或某一集打开播放器。播放器立即显示片名和加载状态，弹幕在后台准备。左上角「返回」取消打开。打开失败时显示「这一集现在打不开」并退出，原因记录在播放状态中，可向梨花询问，排查见[常见问题](../help/faq.md#这一集现在打不开)。

一集可以有多个来源：本机、其他设备、Jellyfin 或 Emby。剧集菜单的「文件…」列出各文件及所在设备。

## 播放器菜单

| 菜单 | 内容 |
|---|---|
| 字幕 | 字幕轨、「添加字幕文件…」、时间偏移；「样式」：颜色、字体、粗体与斜体、不透明度、描边、阴影、位置、对齐、边距、ASS 样式覆盖；「字幕列表」：全部台词，点击跳转 |
| 弹幕 | 开关、速度、透明度、合并相同弹幕、时间偏移；「样式」「屏蔽词」；「弹幕轨道」：开关、移除、「添加弹幕文件…」；「弹幕列表」；「发送弹幕」（需登录弹弹play）；「保存为 JSON」「保存为 XML」 |
| 音轨、剧集 | 切换音轨；切换同一作品的其他集 |
| 「⋯」 | 倍速（可手动输入）、画面比例、截图、截取 GIF、画中画、分离窗口、章节；「播放设置」：快进快退步长、长按倍速、进度条预览、弹幕密度；Jellyfin、Emby 来源的清晰度（原画、转码）；「播放信息」：内核、来源、容器、分辨率、编码与码率、动态范围、帧率、解码方式、音频，底部「复制诊断」 |

样式菜单只列出当前内核支持的项目。

快捷键：空格暂停与继续；左、右方向键快退、快进，长按右方向键按设定倍速播放；`.`、`,` 逐帧前进、后退。Alpha 2 的 Next 播放器使用固定快捷键。

## 播放内核

「设置」→「播放」→「播放器内核」选择解码与渲染引擎，可选项因平台而异：

| 内核 | 特点 |
|---|---|
| Erika | NipaPlay 自研内核（Rust）。按平台使用 Metal、D3D11 或 Vulkan，原生视图输出 HDR/EDR；字幕（含 ASS）和弹幕由内核绘制在画面中；提供实时神经超分辨率 |
| MDK | 硬件解码，格式覆盖广 |
| Media Kit（libmpv） | mpv 的格式兼容性；支持 Anime4K 着色器（「Anime4K 画质预设」） |
| Video Player | 系统播放器 |

更换内核从下一次打开媒体时生效。字幕样式和弹幕设置由各内核共用，生效的项目因内核而异。「设置」→「播放」中的「Erika 超分辨率」适用于低分辨率动画片源，GPU 负载随之增加。

梨花可以读取当前内核的状态和属性，按请求调整或更换内核。

## 字幕与弹幕

- **字幕**：视频内嵌字幕轨；同目录的外挂字幕；通过「添加字幕文件…」或梨花导入的字幕文件，导入后保存为应用数据。梨花可以查找字幕、导入、标注语言并设为默认。
- **弹幕**：按作品与剧集的身份从弹弹play 等来源获取，获取后持久保存。作品尚无弹弹play 身份时，本地文件按弹弹play 文件哈希匹配，唯一命中时加载。剧集菜单的「弹幕…」可添加或导入弹幕，「让梨花准备」交给梨花。

## 续播与观看记录

- 播放进度自动记录，下次从该位置打开。Erika 直接从续播位置开始解码。
- 「动态」→「观看记录」列出最近观看；作品详情中可将剧集标记为看过或未看。
- 观看进度与 Classic 共用。绑定 Bangumi 后，「设置」→「账号」中可开启观看记录同步。

## 播放中对话

播放时打开对话，梨花获得当前作品、剧集和播放位置：

> 跳到 12 分钟。

> 换成简体中文字幕。

> 屏蔽这几个词的弹幕。
