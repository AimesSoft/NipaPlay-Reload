# 下载

## 下载后端

| 后端 | 支持 |
|---|---|
| 内置 BT 引擎 | 磁力链接、种子文件 |
| 内置 HTTP | 普通文件下载 |
| qBittorrent | 本机或远端（家用服务器、seedbox）的 qBittorrent Web UI |

添加 qBittorrent：「设置」→「下载」→「qBittorrent」→「添加」，选择「本机」或「远端」，填写名称、Web UI 地址、用户名、密码和下载位置，「检查」显示「连接正常」后保存。seedbox 的 HTTP Basic 认证可在同一处填写。远端 qBittorrent 下载的文件位于远端机器，本机播放前需取回，或通过 SMB、组网访问；取回可由梨花编写个人工具完成，例如 sftp 脚本。

## 交给梨花

> 找这部动画第 3 集的资源，比较字幕组和版本，下载后整理进媒体库。

梨花的工作内容：

1. 用个人 harness 中的工具搜索资源（预置 Mikan 等资源站的搜索工具），比较版本、字幕组和大小。选择取决于用户偏好且偏好未知时，以提问的形式请用户选择。
2. 添加下载。用户接下来要看的一集优先处理。
3. 文件完成并通过校验后登记进媒体库，梨花绑定作品身份、补全资料。

单项操作同样可以交给梨花：

> 预览这个种子里有哪些文件。

> 这个下载完成或卡住时告诉我。

> 暂停所有下载。

资源站、种子和下载器的可用性取决于外部服务。

## 在界面上下载

「动态」→「下载」→「新建下载」：

1. 粘贴磁力链接或种子地址，或拖入种子文件。
2. 文件列表中选择「全部」「只要视频」或逐个勾选；「存到」选择保存位置。
3. 「下载」。

下载列表支持「暂停」「继续」「重试」和「限速」。删除任务时选择：

| 选项 | 结果 |
|---|---|
| 只移除任务 | 移除任务记录，文件保留 |
| 连同文件删除 | 删除已下载的文件，需在本机确认 |

## 任务状态

| 状态 | 含义 |
|---|---|
| 下载中 | 正在接收数据 |
| 没有进展 | 一段时间内没有新数据 |
| 排队、已暂停 | 等待或暂停中 |
| 完成 | 下载完成 |
| 磁盘满了、没有写入权限、找不到来源、没能下载 | 失败，原因见[常见问题](../help/faq.md#下载器报错) |

点开任务可查看已连接与已知的节点数、剩余空间。完成并通过校验的文件登记进媒体库。

同一组网中其他设备的下载显示在「动态」中并标注所在设备，暂停和取消在所在设备上执行。
