# 下载

## 下载后端

Next 内置 BT 下载引擎，支持磁力链接和种子文件；也支持普通 HTTP 文件下载。此外可以接入 **qBittorrent** 作为下载后端，既可以是本机的，也可以是家里服务器或 seedbox 上的：

1. 打开「设置」→「下载」→「qBittorrent」，点「添加」。
2. 选择「本机」或「远端」，填写名称、Web UI 地址、用户名和密码，以及下载位置。
3. 点「检查」，显示「连接正常」后保存。

- 显示「名称或地址不对」或「连不上」时，检查 Web UI 地址、端口和登录信息。seedbox 支持 HTTP Basic 认证。
- 远端 qBittorrent 下载的文件在远端机器上。要在本机播放，需要把文件取回来，或者通过组网、SMB 等方式访问。取回这一步可以让梨花用个人工具完成，例如写一个 sftp 取回脚本。

## 在界面上下载

1. 打开顶栏「动态」→「下载」，点「新建下载」。
2. 粘贴磁力链接或种子地址，或者直接拖入种子文件。
3. 在文件列表里选「全部」或「只要视频」，也可以逐个勾选；「存到」选择保存位置。
4. 点「下载」。

下载列表里可以「暂停」「继续」「重试」，也可以「限速」。

删除任务时会让你选择：

- 「只移除任务」：文件留在原处；
- 「连同文件删除」：会删除已下载的文件。

## 交给梨花

下载最常见的用法是直接说目标：

> 帮我找这部动画第 3 集的资源，比较一下字幕组和版本，选好后只下载第 3 集，完成后整理进媒体库。

梨花会：

1. 用个人工具搜索资源（预置了 Mikan 等资源站的搜索工具），比较版本、字幕组和大小，必要时问你选哪个；
2. 添加下载，并声明文件和剧集的对应关系；
3. 等任务完成、校验后，把文件登记进媒体库，再按声明的对应关系匹配到剧集。

你也可以只让她做其中一步：「预览这个种子里有哪些文件，只下第 1 集」「这个下载完成后告诉我」「暂停所有下载」。

只下载你有权获取的内容。资源站、种子和下载器的可用性不在 NipaPlay 的控制范围内。

## 状态怎么看

- **"已开始"不等于"已完成"**：添加下载只代表任务提交了。进度在「动态」→「下载」，梨花也可以等任务结束后汇报。
- **完成之后**：下载的文件需要完成校验，才会登记进媒体库；登记之后仍需要匹配身份，除非添加下载时已经声明了文件和剧集的对应关系。
- **组网的设备**：同一组网里其他设备上的下载也会显示在「动态」里，并标注所在设备；这些任务只能在它所在的设备上暂停或取消。

下载失败时，界面和任务信息会显示原因，例如没有连接的节点、磁盘空间不足、qBittorrent 认证失败。排查方法见[常见问题](../help/faq.md#下载器报错)。
