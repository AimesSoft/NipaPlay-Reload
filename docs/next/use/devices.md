# 多台设备

## 组网（Mesh）是什么

同一个弹弹play 账号下的设备可以组网：互相发现、合并媒体库、跨设备播放，还可以把任务交给另一台设备上的梨花。

- **数据各自保存**：每台设备有自己的数据库、对话、记忆和个人 harness，组网不会复制整份数据库。操作在实际持有数据或能力的那台设备上执行。
- **媒体直连传输**：协调服务只负责身份认证和交换地址，视频在设备之间直接传输，不经过服务器，也没有中继。所以**两台设备必须网络互通**：同一局域网，或者通过 overlay 网络、SSH 转发等方式能直接连上。NAT 和防火墙可能阻止连接。

## 加入组网

1. 两台设备都开启 Next，并登录同一个弹弹play 账号。没有登录时，设备页会提示「请先登录弹弹play账号」。
2. 分别打开「设置」→「设备」，在「组网」里点「加入」，处理弹出的提示。
3. 在设备列表里确认对方在线。

设备页的其他选项：

- **本机名**：在其他设备上显示的名字。
- **在局域网里让别的设备发现**：局域网广播发现。
- **端口、其他地址**：手动指定监听端口，或补充可达地址，例如 overlay 网络地址。
- **信任的设备**：列出已认证的设备，可以「移除」不再信任的设备。

Windows 安装程序会为专用和域网络添加防火墙放行规则；如果你改用便携包，或者网络被识别为公用网络，可能需要自己放行。

## 加入意味着什么

加入组网，意味着信任同账号下已认证的设备：它们可以调用本机开放的能力，读取这个进程能访问的文件。这比"共享媒体库"的范围大，而且没有单独的媒体库共享开关。

「允许别的设备在这里运行程序」是另一项独立授权。开启后，其他设备上的梨花可以在本机执行程序，按需要再开。

只加入你信任的设备。同一局域网并不意味着安全，设备认证也不能防止受信任的梨花出错。

## 跨设备看片

1. 在持有视频的设备（例如桌面 A）上添加并扫描文件夹。
2. 在另一台设备（例如 iPad B）的媒体库里找到对应作品，播放并检查画面、声音和进度。

作品没出现时，先确认 A 的扫描结果，再检查网络。设备离线时，片库里可能还显示上次读到的目录，但只在离线设备上的文件无法播放。不要凭缓存卡片判断能不能播。

## 在 iPad/iPhone 上使用梨花

iPhone/iPad 提供 Next 界面、播放器和组网，但**不在本机运行梨花**，要用另一台设备上的梨花对话：

1. 在桌面（或 [Linux 无界面版](../advanced/headless.md)）上[配置好梨花](../start/setup-nipa.md)，保持 Next 运行。
2. 两台设备按上面的步骤加入组网。
3. 在 iPad/iPhone 打开「设置」→「梨花」，选择正在运行梨花的设备。
4. 打开对话，发一句测试消息，确认回复来自那台设备。

设备列表里每台设备会显示状态：「不在线」「没有运行梨花」「忙」「空闲」。显示「没有运行梨花」时，检查那台设备上的 Next 界面、模型和运行环境是否就绪。在手机上下载运行环境解决不了这个问题。

她在远端设备上工作时，操作发生在**她所在的设备**上：改的是那台设备的数据库、布局和文件。删除本机文件、登录账号这类操作仍需要在 iPad/iPhone 上确认。

## 跨设备分派任务

可以让一台设备上的梨花把工作交给另一台：

> 看看哪些设备在线；让工作站上的梨花下载这部，下好后告诉我。

委托要求目标设备上的梨花正在运行。同一组网里各设备的后台任务会统一显示在「动态」里并标注所在设备，但只能在它所在的设备上暂停或取消。
