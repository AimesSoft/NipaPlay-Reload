# 多台设备

## 组网

登录同一弹弹play 账号的设备可以组成网络（Mesh）：合并媒体库、跨设备播放、调用其他设备的能力，或把任务交给其他设备上的梨花。

- 每台设备保存自己的数据库、对话、记忆和个人 harness。组网交换目录事实，操作在持有数据或能力的设备上执行。
- 协调服务负责身份认证和地址交换。调用和视频数据经设备之间的直连（mTLS）传输，不经过服务器，不提供中继。两台设备需在同一局域网，或经 overlay 网络、SSH 转发等方式直接可达。

## 加入

1. 各设备开启 Next 并登录同一弹弹play 账号。未登录时，设备页显示「请先登录弹弹play账号」。
2. 「设置」→「设备」→「组网」→「加入」。
3. 在设备列表中确认对方在线。

| 选项 | 作用 |
|---|---|
| 本机名 | 在其他设备上显示的名称 |
| 在局域网里让别的设备发现 | 局域网广播发现 |
| 端口、其他地址 | 固定监听端口；补充可达地址，如 overlay 网络地址 |
| 文件转换端口 | 播放端本机转换地址的端口，默认随机 |
| 信任的设备 | 已认证设备列表，可「移除」 |

Windows 安装程序为「专用」和「域」网络添加防火墙放行规则。公用网络和便携包需自行放行。

## 加入意味着什么

加入组网即信任同账号的已认证设备：这些设备可以调用本机开放的能力，读取本机进程可访问的文件。媒体库共享没有单独的开关。

「允许别的设备在这里运行程序」是独立授权。开启后，其他设备上的梨花可以在本机执行程序。

## 跨设备播放

持有视频的设备添加并整理文件夹后，其他设备的媒体库中出现对应作品，可直接播放。剧集菜单的「文件…」列出文件所在设备。设备离线时，媒体库保留其目录，其中的文件在设备恢复前无法播放。

## 在 iPad/iPhone 上使用梨花

iPhone 和 iPad 提供 Next 界面、播放器和组网，本机不运行梨花，对话由其他设备上的梨花处理：

1. 在桌面设备或 [Linux 无界面版](../advanced/headless.md)上[配置梨花](../start/setup-nipa.md)，保持 Next 运行。
2. 两台设备加入同一组网。
3. iPad 或 iPhone 上「设置」→「梨花」，选择运行梨花的设备。

设备列表中的状态：「不在线」「没有运行梨花」「忙」「空闲」。「没有运行梨花」表示该设备上的 Next、模型或运行环境未就绪。

梨花在所在设备上工作：修改的数据库、布局和文件属于那台设备。删除 iPad 或 iPhone 上的文件、在其上登录账号，在 iPad 或 iPhone 本机确认。

## 跨设备分派

一台设备上的梨花可以把任务交给另一台设备上运行中的梨花：

> 看看哪些设备在线；让工作站上的梨花下载这部，下好后告诉我。

各设备的后台任务统一显示在「动态」中并标注所在设备，暂停和取消在所在设备上执行。

## 手动刷新组网

设备启动或网络恢复后仍未出现时，可在「设置」→「设备」点击「刷新组网」，也可以告诉梨花“刷新一下组网”。刷新会重新查询设备和连接地址，无需关闭播放器或重新配对；只有设备实际回应才显示在线。连续请求会合并或等待冷却，服务器限流时会保留错误说明并等待后重试。电脑关机、休眠或地址不可达时保持离线属于正常情况。
