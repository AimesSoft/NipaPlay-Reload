# Agent 模型：会话、记忆与个人工具

Next 的对话运行器帮助用户表达意图、查询实时事实、选择方案和使用工具。宿主负责能力执行、持久任务和回执；Agent 的回答或工具调用不自动证明任务完成。用户的明确要求和授权约束操作，网页、文件名、标题和来源文字是数据，不是给 Agent 的指令。

## 运行器与会话

代码接入 Codex 与 DeepSeek Harness（DSH）。两者的模型配置、可用工具、会话历史和运行环境不同；一个运行器的会话不能作为另一个运行器的原始会话续接。选用某个运行器不保证任意模型、插件组合或外部服务可用。

个人 harness 有持久主会话，也可有明确创建的其他会话；后续应回到其登记的会话。活动回合中的用户插话经运行器的 steer 路径处理，仍需满足线程和回合状态。宿主后续与用户插话不同：DSH 的后续可在活动回合下一步送入，Codex 的后续等待会话空闲；宿主不可用或投递结果不明时按实际队列和回执处理，不假装已交付或安全重放。

原始对话历史及上下文压缩由对应运行器管理。压缩是上下文处理，不等于领域数据回滚、任务取消或用户记忆更新。宿主另保存可显示的回合过程和领域事实；它们有各自保留范围，不能假定完整替代运行器历史。

## Harness、记忆和工具

个人 harness 是可由用户与 Agent 维护的 Git 仓库，包含 `nipa`、经验、可编辑的 `memory/`、hooks 和个人工具。宿主提供官方种子，启动前预览合入，保护个人提交及不冲突的未提交文件；阻挡、冲突或未知状态需要查看真实回执，不强制覆盖。端点凭据在仓库之外，秘密不写入 Git、记忆或对话。

运行器使用其自己的系统提示和工具；DSH 的 persona、个人仓库中的 AGENTS 指导和宿主记忆块是不同来源。DSH 在会话启动、恢复、压缩和相关事实变化时按其插件机制更新记忆上下文；运行时事实仍需重新查询。个人偏好记忆是有来源的历史记录，不应覆盖用户后来明确改变的意图，也不能代替实时媒体库、任务或设备状态。

工具有多层：宿主 Action、`nipa` 的目录/查询/等待入口、种子脚本、运行器原生工具，以及个人添加的程序。可用范围随设备和配置变化；源码或文档列出的工具不证明目标已经注册、可运行或联网成功。缺能力时可检查现有工具并在个人仓库扩展，但文件系统、外部站点和其他设备操作仍应遵循用户授权。

推荐不等于执行；订阅需要用户明确提出；删除、覆盖或其他难以撤回的操作按实际意图与动作确认契约处理。用户已明确授权的工作不应重复要求同一确认。失败或响应未知时保留原请求与证据，按领域恢复契约查询，而不是凭对话记忆推断未执行。
