# Next 应用模型

这些文章说明 NipaPlay Next 中事实的含义和归属，帮助理解工作过程；它们不是工具参数手册。具体宿主注册、输入输出和当下状态，以目标设备的实时目录、`describe`、能力事实和回执为准。

- [媒体模型](media-model.md)：作品层级、文件区间、身份、来源资料与展示。
- [执行模型](execution-model.md)：Action、任务、事件、提交和恢复。
- [设备模型](device-model.md)：宿主角色、Mesh、设备数据与界面归属。
- [Agent 模型](agent-model.md)：对话运行器、个人 harness、记忆和授权。

按实际任务操作可读[任务指南](../development/guides/README.md)；项目的设计假设在[研究纲领](../RESEARCH.md)。
