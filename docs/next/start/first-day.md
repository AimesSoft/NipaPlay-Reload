# 第一次使用

## 分工

Next 的媒体库由梨花维护。

| | 负责 |
|---|---|
| 用户 | 提供媒体来源，提出目标和偏好 |
| 梨花 | 识别文件对应的作品、季和集，绑定 TMDB、Bangumi、弹弹play 的身份，获取并写入标题、简介、海报、背景、Logo、剧集标题和截图，按授权整理目录和文件名 |
| NipaPlay | 扫描文件，执行梨花的工具调用，保存身份与资料及其来源，播放、下载、加载弹幕 |

文件与作品分开记录。扫描登记文件的路径、大小和技术信息；梨花绑定身份后，文件归入作品，详情页显示资料，弹幕按身份加载。

## 添加本机文件夹

入口：

- 首页：媒体库为空时显示「添加文件夹」；
- 「设置」→「媒体来源」→「本机文件夹」→「添加文件夹」。

选择目录后立即扫描。扫描结束，NipaPlay 将这批文件交给梨花，梨花开始识别和补全资料。这一行为由「设置」→「梨花」→「添加文件夹后交给梨花整理」控制，默认开启；梨花未运行时请求排队。

也可以直接在对话中提出：

> 把 ~/Movies/动画 加进媒体库并整理好。

## 整理过程

- 对话中「这次对话在后台做的事」和「动态」→「进行中」显示后台任务。
- 需要用户决定的事项以提问出现在右下角，梨花同时继续其余工作，回答送回原对话。
- 用户接下来要看的一集优先处理。

目录和文件名的整理方式由「设置」→「梨花」→「目录和文件名整理」决定：

| 选项 | 行为 |
|---|---|
| 询问我（默认） | 梨花询问是否整理，以及该决定只用于本次还是作为以后的规则 |
| 保持原样 | 不移动、不改名 |
| 按规则自动整理 | 按「目录和文件名规则」整理以后添加的文件夹 |

整理范围限于添加的根目录，不删除、不覆盖文件。字幕、弹幕、观看进度与文件的关联随文件保留，无法保留关联的文件跳过并报告。

## 结果

整理完成的作品，详情页显示背景、Logo、标题、简介、剧集列表、每集标题和截图、演职人员等资料，具体项目取决于来源收录的内容。资料来源和缺项可以向梨花询问：

> 这部的资料还缺什么？

## 播放

在作品详情点「播放」或某一集。弹幕按作品身份自动加载并保存。播放器的使用见[播放](../use/playback.md)。

## 其他来源

SMB、WebDAV、Jellyfin、Emby 和其他设备的添加方法见[媒体库与来源](../use/library.md#来源)。这些来源的内容同步后出现在媒体库中；识别和补全资料由用户在对话中提出：

> 整理一下 NAS 上「动画」目录里的作品。

Classic 中已有的识别结果，可以请梨花导入。

## 修正

识别有误时，在对话中说明正确的作品：

> 这部应该是 2019 年的剧场版。

梨花重新绑定并更新资料。作品详情的操作菜单中也提供「匹配作品…」和「编辑资料…」，用于直接修改身份和资料。
