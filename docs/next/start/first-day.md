# 第一次使用

这一篇用一个测试视频走完整条路：添加文件夹 → 扫描 → 匹配作品 → 弹幕 → 播放，最后让梨花做一件事。先用一个只放了一两个视频的文件夹，不要一上来就对整个大目录做批量操作。

## Next 怎样理解你的文件

Next 把"文件"和"作品"分开记录：

- **扫描**只登记文件本身的事实，例如路径和大小。扫描完成后，片库里会出现由文件生成的条目。
- **匹配**才确定身份：这个文件属于哪部作品、哪一季、哪一集。确定后才会有封面、简介、演职人员，弹幕也才能对上。

Next 不会擅自猜测身份。文件名相似、搜索结果排第一，都不等于确认。匹配可以由你在界面上完成，也可以交给梨花：她会先列出候选和依据，由你确认后再写入。

Classic 里已有的匹配不会自动带过来，可以让梨花"导入 Classic 的匹配"。

## 1. 添加文件夹并扫描

1. 打开「设置」→「媒体来源」，在「本机文件夹」卡片点「添加文件夹」，在系统选择器里选中测试视频所在的目录。
2. 点这个文件夹的「扫描」（或「全部扫描」）。界面提示「已开始」只表示扫描任务已经启动；进度可以在顶栏「动态」的「进行中」里看到。
3. 扫描完成后打开「媒体库」，找到这个文件对应的条目。

设置 →「梨花」→「提醒与整理」默认开启时，**通过界面添加文件夹后，梨花会接手识别和补资料**，并在需要你决定时在右下角提问，例如目录和文件名要不要整理。不想让她介入可以关掉这项。之后后台新增的文件和重新扫描不会自动唤起她。

## 2. 匹配作品

1. 打开这个条目的作品详情，在操作菜单里选「匹配作品…」。
2. 选择资料来源，用准确的片名搜索。核对候选的标题、年份和类型（电影或剧集）后选中。
3. 剧集要把文件对应到具体集数，电影没有这一步。一个文件包含多集这类特殊情况，可以交给梨花处理。
4. 核对无误后点「匹配」。

完成后，详情页会显示封面、简介和剧集列表；演职人员、图片和完整资料取决于来源有没有提供。没有可靠的候选时不要硬选，换个名字或换个来源再搜；搜索依赖网络和来源服务。

## 3. 弹幕

在作品详情的剧集操作菜单选「弹幕…」：

- 「添加弹幕」：在线搜索并核对后添加；
- 「导入文件」：导入本机已有的弹幕文件。

不是每一集都能在线找到弹幕，没有就跳过。也可以点「让梨花准备」交给她。

## 4. 播放

回到作品详情点「播放」或某一集。播放器会立即打开并显示加载状态，左上角返回可以取消。打不开时显示「这一集现在打不开」，见[常见问题](../help/faq.md#这一集现在打不开)。

播放后检查：

- 画面、声音和弹幕是否正常；
- 拖动进度、退出后重新进入，看看能否从刚才的位置续播。

匹配成功不代表一定能播放：播放器内核不支持该格式、文件不可读、远端设备离线，都会导致播放失败。见[播放](../use/playback.md)。

## 5. 和梨花说第一件事

点顶栏右侧打开对话，试一个只读的小任务：

> 看看媒体库里刚添加的这部作品，告诉我它匹配到了哪部、有几集、哪几集有弹幕。

她会调用查询类工具（对话里出现「翻媒体库」「查资料」之类的步骤），再根据结果回答。核对她说的和详情页显示的是否一致。

再试一个需要写入的任务：

> 把这部作品放到首页，建一个叫"测试"的书架。

写入类操作完成后，到首页看结果。

删除下载的文件和部分敏感设置会请求你确认；但她通过命令行或脚本操作文件时，不一定会再弹窗。下一篇会讲怎样提要求、怎样看她做了什么。
