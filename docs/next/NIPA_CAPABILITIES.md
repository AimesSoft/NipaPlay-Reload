# 可以让梨花做什么

可以直接说目标、范围和希望保留的东西，无须知道工具名。下面是当前实现中可请求的场景，不表示每台设备、每个模型或服务都能完成：实际能力取决于目标宿主、授权、网络、登录和数据。梨花应先查事实；部分写入提供预演或回执，下载文件删除和部分敏感设置会请求用户确认；请核对实际结果。回答或任务受理不等于执行完成。

## 首页和媒体库怎么呈现

- **主视觉**：“把《某作品》放到首页大图。”梨花可以选一部作品作为首页主视觉；背景、Logo 和资料来自该作品已有资料。一次显示一部，不提供可配置轮播；未指定时首页有自己的选择顺序。
- **首页书架**：“在首页摆一排‘周末想看’，放这几部，按这个顺序。”可以创建、更新或移除梨花摆的书架，并指定其中作品的顺序；书架作品须已有资料记录，不要求已有本地视频。继续观看、今天更新和最近添加等是首页已有区域，是否有内容取决于数据。
- **媒体库分类**：“按未看完的动画建一个类别，以后新符合条件的也放进去。”条件类别持续按本机数据计算，支持来源、设备、类型、观看状态、类型标签、年份、评分和添加时间；未知值不满足相应条件，服务器作品须有已接受的身份。“把这几部放一起”可建手选类别；也可保留服务器库或文件夹的来源原样。整理和原始结构可以切换，也可选择卡片或书架形式。
- **原始类别**：“把这个来源的某个分类隐藏，调整顺序；以后再恢复。”这些操作只影响本机展示，不改服务器或共享目录；离线来源可能显示旧目录，不能保证播放。
- **对话卡片**：“把候选作品和下载进度摆出来给我选。”梨花可以在回复下展示作品、剧集、任务或选项卡片；卡片状态随数据变化。选择候选前仍需核对。

选择主视觉作品、修改作品图片和生成新图片是三件事。例如“用我给你的这张图片做《某作品》的背景”：梨花可以把已有本地图片或可访问的 HTTP(S) 图片链接设为作品海报、背景、Logo 或剧集截图，无须图片生成能力；这会影响作品资料展示，而不只是首页位置。请注明作品、图片角色和来源。生成新图片需要另有可用的生成工具或服务，不能因支持设置图片就假定内置生成能力。当前提供的是书架、分类和卡片等明确入口，不是任意改写应用界面布局。[开发者参考](CAPABILITIES.md)

## 找片、资料与整理

- **查找和来源**：“在本机和在线设备里找这部片，告诉我哪些集可播放。”可以查询合并目录、文件和来源；SMB、WebDAV、Jellyfin、Emby 等须先配置并可访问。离线缓存不是实时可播保证。
- **识别与绑定**：“检查这个文件可能是哪一集，先列出候选和依据，再等我确认。”可以搜索资料并将作品、剧集和文件明确绑定；候选或同名不等于已确认的身份。Classic 旧匹配需要显式导入。
- **整理与合并**：“这两条是同一部作品，先预览合并和每集对应关系。”可以预览、提交合并，符合条件时撤回；请检查季、集和文件映射。后续关系变化可能阻止撤回。移除目录记录不等于删除原文件。
- **资料与图片**：“把简介改成这段，把这张图设为海报；保留原始来源。”可以编辑标题、简介、年份、剧集信息与图片覆盖，也可清除覆盖以显示来源资料。图片须可读取且可解码；不要把候选当已核实事实。
- **定位文件**：“在文件管理器里显示这一集的本地文件。”实际打开的是文件所属设备上的文件管理器；远端文件与本机路径不能混同。[开发者参考](CAPABILITIES.md)

## 下载、播放与观看

- **下载**：“预览这个种子里有哪些文件，只下载第 1 集，完成后告诉我。”支持的来源包括磁力链接、种子和 HTTP 文件，以及已配置的下载后端。可查看进度、暂停、继续或取消支持的任务；文件完成并校验后可入库，仍需要明确识别。删除下载数据有单独确认，移除任务不等于删除文件。
- **播放**：“继续播放这部作品；跳到 12 分钟并告诉我当前播放状态。”可查询播放状态、打开可播放文件、暂停、定位和选择轨道；依赖目标有播放器、文件可读且内核支持。定位受理后应再核对实际位置。
- **弹幕与字幕**：“为这一集搜索弹幕，列出候选；导入我选的字幕并设为中文。”可以查询、导入、选择与调整已有轨道；来源可能没有结果或需要网络。导入的内容保存为应用数据，删除或替换前先核对。
- **进度和历史**：“列出最近继续观看的作品，把这几集标为看过。”播放会记录进度；可查询和修改支持的观看状态。删除观看记录不删除视频；账号收藏同步是另一项操作。[开发者参考](CAPABILITIES.md)

## 账号、设置和个人记忆

- **账号与同步**：“检查 Bangumi 登录状态，列出我的收藏；把这部标为看过。”可查询及更新受支持的账号收藏，按服务实际返回结果。登录窗口和密码由用户处理；WebDAV 同步需先配置并登录，运行同步后检查结果。
- **设置**：“把字幕语言优先设为中文，告诉我何时生效。”可查询和修改支持的设置，部分设置需重新打开媒体或重启；某些敏感路由或授权更改需要用户确认。Classic 与 Next 共享部分设置。
- **记忆**：“记住我通常喜欢中文字幕；列出你记得的偏好。”可查看和调整个人记忆；不同设备的梨花各自保存记忆。记忆、持久对话历史和压缩后的上下文是不同东西，见[使用指南](USER_GUIDE.md#对话历史上下文和记忆)。不要把密码或 API key 交给记忆。
- **发现与插件**：“看看今天的放送和推荐。”依赖弹弹play 等来源可用；应用插件也可查询和管理，具体取决于宿主及已安装插件。[开发者参考](CAPABILITIES.md)

## 跨设备、后台工作与扩展

- **Mesh**：“查看哪些设备在线，从工作站上的片库找这部；让那台设备的梨花处理并回报。”设备须同账号、加入组网、认证且网络可达；委托还要求目标梨花正在运行。每台设备有自己的数据库和记忆；加入组网意味着信任设备访问本机开放能力和可访问文件，详见[组网](USER_GUIDE.md#mesh-设备组网)。
- **任务与后续**：“这个下载完成或失败后告诉我；现在列出所有进行中的任务。”可以查看任务及回执、控制支持的任务并订阅后续；取消不自动删除文件。返回已受理不代表完成，断线时应查询任务和回执。
- **定时与事件**：“每天晚上检查新入库作品并告诉我结果。”可在个人 harness 中配置定时程序或事件 hook；需要明确目标与授权，脚本只在 NipaPlay 运行且 Next 开启时执行，不能保证关机期间运行。请先检查计划和脚本。
- **个人工具和 SQL**：“先只读检查媒体目录中重复绑定；预览修正，不要立即提交。”可使用个人 harness 中的脚本和工具，也可查询 Next 数据库，受支持的写入先预演再提交并保留回执，符合条件时可撤回。SQL 不是任意数据库管理员权限；通过 Mesh 在目标设备运行程序需要目标设备单独开启远程运行程序授权。复杂批量修改前先备份。[开发者参考](CAPABILITIES.md)

## 状态、排错与系统操作

- **诊断**：“为什么这集播不了？检查播放错误、来源连接和设备状态。”可读取已有诊断、网络观察和任务事实，必要时做明确的连接检查；没有观察到不等于在线或离线。日志可能含个人信息，分享前检查。
- **存储与缓存**：“哪些目录占空间？先预览能安全清理的缓存。”可查看空间与可回收缓存计划；持久弹幕、字幕及用户下载不当作普通缓存自动回收。删除用户文件或覆盖要按实际确认流程处理。
- **窗口、通知和分享**：“打开作品详情，调整窗口大小；准备分享这张截图。”可操作受支持的窗口并打开系统分享面板，由用户选择目标；打开面板不等于已分享。通知依赖系统授权与平台支持，当前原生通知以 macOS 为限。
- **应用与来源状态**：“检查更新并打开发布页；检查媒体服务器连接。”可查询或检查实际状态；打开发布页不等于自动下载安装。部分操作、截图和播放能力需要图形宿主。

这些示例覆盖当前主要能力族，不保证每个具体动作都在所有宿主注册。无法获取的来源、权限不足、模型判断错误或远端离线都可能使任务失败；请让梨花说明未完成部分。完整能力与当前设备的检查方法见[开发者参考](CAPABILITIES.md)。
